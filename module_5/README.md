# Module 5 — JavaScript Practice

This folder contains my Module 5 JavaScript practice and assignment work for the SQA course.

## Topics Practiced

* Functions
* Loops
* Conditional statements
* Arrays
* Strings
* Mathematical operations
* Basic problem solving

## JavaScript Programs

The `code` folder contains the following programs:

| File                       | Description                                      |
| -------------------------- | ------------------------------------------------ |
| Celsius_to_Fahrenheit.js   | Converts Celsius temperature to Fahrenheit       |
| factorial.js               | Calculates the factorial of a number             |
| fizzbuzz.js                | Implements the FizzBuzz problem                  |
| palindrome.js              | Checks whether a string or value is a palindrome |
| sum_of_array.js            | Calculates the sum of values in an array         |

## How to Run

Make sure Node.js is installed on your computer.

Run a program using:

```bash
node code/factorial.js
```

Replace `factorial.js` with the name of any other JavaScript file.
